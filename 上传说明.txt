此文件夹已整理好，可用于上传 GitHub。
版本：1.3.4-mod.1

上传方式：
1. 打开你自己的 GitHub 仓库，选择 Add file → Upload files。
2. 打开本文件夹，全选里面的文件和文件夹，拖入 GitHub 上传页面。
3. 必须保留 dist、src、scripts，以及 manifest.json 等根目录文件。
4. 不要把“柏宝书-GitHub上传版-1.3.4-mod.1”这一层文件夹整体套到仓库里。
5. 提交后，仓库首页应直接能看到 manifest.json、dist、src。

不包含 node_modules 和 .git，无需自行删除依赖。
这是本地整理好的待上传版本，尚未替你上传 GitHub。

酒馆安装时填写你上传后的仓库地址，不要使用原作者仓库地址，否则装到的不是本次改版。
如果原插件已安装，先备份再更新替换，避免同时启用两份柏宝书。
